## 💼 Опыт

**4 года 6 месяцев коммерческой разработки**

Работал над продуктовой разработкой внутренних систем (Laravel + React + TypeScript), публичными сайтами на MODX, фриланс-проектами на Bitrix. От проектирования БД и API до деплоя с CI/CD в Kubernetes.

**Основная разработка ведётся в приватных репозиториях компаний** — здесь мои личные эксперименты и открытые проекты.

### Что делал:
- Сложные интерфейсы на React + TypeScript с WebSockets и real-time обновлениями
- Backend на Laravel: очереди, cron-задачи, REST API, интеграции (CRM, платёжки, SOAP)
- Полный цикл от идеи до продакшена: проектирование БД, права доступа, автоматизация
- Парк сайтов на MODX, интеграции и кастомная разработка на Bitrix
- CI/CD pipeline, Docker, деплой в Kubernetes
